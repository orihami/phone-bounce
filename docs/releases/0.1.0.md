## Phone Bounce 0.1.0（最初の版）

DVDのロゴが、スマホの画面に見えているウィンドウの枠で跳ね返り続けます。Windows 用の Desktop Bounce のスマホ版です。

- **常駐**: アクセシビリティサービスとして動きます。一度オンにすれば、再起動しても自動で起動します。
- **跳ね返る相手**: 画面の端、キーボード、分割画面・小窓のアプリ。反射のたびに色が変わります。
- **押し出し・侵入・脱出**: 窓が動いてロゴにぶつかると押されます。勢いよくぶつかる・挟まれる・ロゴの上に窓が開く、のどれかで、ロゴが窓の中に入って半透明になり、窓と一緒に運ばれます。一定時間で、その窓の枠をすり抜けて出ます。
- クリックは素通りします。ほかのアプリの操作の邪魔になりません。
- クイック設定のタイル「跳ねるロゴ」で、一時停止・再開。画面が消えている間は止まります。

### 入れ方
1. この APK をダウンロードして入れる。
2. アプリを開き、「アクセシビリティの設定を開く」から Phone Bounce をオンにする。
   灰色でオンにできないときは、設定 → アプリ → Phone Bounce → ︙ → 「制限付き設定を許可」。
3. 電池の最適化を除外すると、止められにくくなります（任意）。
