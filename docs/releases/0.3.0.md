## Phone Bounce 0.3.0（画面の部品でも跳ね返る＋設定画面を作り直し）

### 新しい: いろんなものでの壁反射
ロゴが、画面の端・キーボード・分割画面の窓に加えて、**画面の中のボタン・画像・入力欄**でも跳ね返ります（設定の「画面の部品」。既定はオン）。
- 種類は選べます: ボタン・入力欄 ／ 画像・動画 ／ 文字の枠（文字の枠は既定オフ）
- ロゴと重なった状態で現れた部品は、離れるまですり抜けます（薄く表示）
- 画面の大部分を占める大きな部品（背景など）は壁にしません

### プライバシーの約束が少し変わりました
これまでは「窓の位置だけ」でしたが、部品の枠を知るために、**部品の位置・大きさ・種類・見えているか・押せるか**も読みます。
**文字の中身・入力した内容・説明文・ID は読みません**（読めない作りにしてあり、テストで毎回確かめています）。通信の権限もありません。
「画面の部品」をオフにすると、これまでどおり窓の位置だけになります。

### 設定画面を作り直し
- 暗い配色のカード型に。いちばん上に、いま選んでいる見た目・文字・速さで**実際に跳ね回る見本**（壁・ボタン・画像の箱つき）
- 状態（常駐中か）と、大きな「オンにする」ボタン
- 見た目は横にスクロールして選ぶ。スイッチ・スライダー・選択肢も作り直し

### 入れ方
前の版の上に、そのまま上書きで入ります（設定も残ります）。

### 未確認
実機での動きは、これからです（部品の読み取りは、アプリによって取れ方が違います。Web ページやゲームでは、取れない部品があるかもしれません）。画面の見た目と動きの計算は、PC 上のテストで確認済み。
