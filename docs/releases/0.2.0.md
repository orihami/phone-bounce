## Phone Bounce 0.2.0（見た目を、元のロゴに合わせて作り直し）

最初の版のロゴ（楕円の輪＋文字）は、元の Desktop Bounce と違っていました。**元のロゴ**（斜めの太字「DVD」＋平たい円盤、真ん中に穴）に作り直し、そこから見た目のバリエーションを作りました。

### 見た目（設定の画面で、見本を見ながら選べます）
- **クラシック**: 元のロゴそのまま（既定）。比率も、元のアプリで測った寸法に合わせています
- **ネオン**: 同じ形で、光る輪郭
- **ブラウン管**: 走査線と色ズレ、ちらつき
- **ドット**: 8ビット風
- **フチどり**: 白いフチと影
- **ディスク回転**: 円盤の上を光が走る
- **画像**: 自分の画像の形で跳ねる（透明な所を抜いた形、透明がなければ明るい所。色は自動で塗られます）

### そのほか
- ロゴの文字を、ワンタップで DVD / VHS / CD / BD / LD / 4K に切り替え
- 見た目の描画テストを追加（全スタイルが描けること、元のロゴの比率を保つことを PC 上で確認）

### 入れ方
前の版の上に、そのまま上書きで入ります（設定も残ります）。

### 未確認
実機での見た目・動きの確認は、これからです（描画は PC 上で確認済み）。
